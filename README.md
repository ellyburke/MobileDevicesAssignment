# MobileDevicesAssignment - DnD Companion App
Welcome to the DnD companion app built under the Mobile Devices assignment. This project, currently in active development, aims to help players manage their characters, spells, and other assets for tabletop sessions on mobile devices.

## Features
- Character management: create, edit, and track your DnD characters.
- Add your friends and see their characters
- Find any race, class, item, spell, background, and monster information.
- Create sessions for specific times and receive a notification when its time to play.

## How to run

1. Clone the repository 
```powershell
git clone https://github.com/ellyburke/MobileDevicesAssignment.git
```
2. Navigate to the app directory

```powershell
cd MobileDevicesAssignment/dnd_app
```

3. Fetch the dependencies
```powershell
flutter pub get
```

4. Run the app
```powershell
flutter run
```
